# Citizen Project

This project is split into a frontend and a backend.

## Structure

- `frontend/`: The React + Vite frontend application.
- `backend/`: The Node.js + Express backend application.
- `ai-service/`: The Python Flask service for AI analysis.

## Getting Started

### All Services
1. `npm install`
2. `npm run dev`

### Individual Services

#### Backend
1. `cd backend`
2. `npm install`
3. `npm run dev`

#### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`

#### AI Service
1. `cd ai-service`
2. `pip install -r requirements.txt`
3. `python app.py`
